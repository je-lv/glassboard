# Security policy

## Supported versions

Security fixes target the latest published Glassboard version. Older versions may require an upgrade.

## Reporting a vulnerability

Use **Report a vulnerability** on the repository's GitHub Security page to send details privately. Include the affected version, setup, steps to reproduce, impact and a minimal demonstration when possible. Do not put tokens, board data or vulnerability details in a public issue.

If private reporting is unavailable, open an issue asking the maintainer for a private contact without including the vulnerability details.
